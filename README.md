# 🦅 SilentSkies

> **Visualizing the disappearance of migratory birds — one year at a time.**

SilentSkies is an interactive 3D globe application that tracks global bird occurrence data over time, highlights at-risk migratory species, and uses AI-powered analysis to explain ecological decline patterns. Built for the **AI 4 World Hackathon**.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🌍 **Interactive 3D Globe** | Real-time heatmap of bird occurrences powered by `react-globe.gl` and Three.js |
| ⏱️ **Time Slider** | Scrub from 2000 → 2025 (with optional monthly resolution) to watch populations shift |
| 🔍 **Species Browser** | Search and select from a curated watch list of ~100 migratory species |
| 📊 **AI Deep Analysis** | Claude-powered grounded synthesis: trend data, IUCN status, and decline drivers |
| 🗺️ **Migration Routes** | Toggle animated migration path overlays on the globe |
| 🚀 **Call to Action Panel** | Personalised, region-aware conservation steps generated by AI |
| 🔔 **Risk Scoring** | Per-species decline risk derived from historical GBIF trend modelling |
| 🎨 **Theming & Settings** | Accent colour themes, HUD style, ambient nature audio, and more |

## 🚀 Getting Started

### Prerequisites

- **Node.js** ≥ 18
- An **API key** for Claude (Anthropic) or any OpenAI-compatible LLM endpoint

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/silent-skies.git
cd silent-skies/SilentSkies

# Install dependencies
npm install
```

### Configuration

Create a `.env` file in the `SilentSkies/` directory:

```env
VITE_OPENAI_API_KEY=your_api_key_here
VITE_OPENAI_BASE_URL=https://api.anthropic.com/v1   # or your preferred endpoint
```

> **Note**: The GBIF Occurrence API requires no API key. All occurrence data is fetched directly from the public GBIF endpoint.

### Running Locally

```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

### Building for Production

```bash
npm run build
npm run preview
```

## 🤖 AI Analysis

The **Analyze** panel uses a RAG-style approach: real GBIF trend statistics and IUCN conservation status are injected as structured context into the LLM prompt. The model is instructed to:

- Explain likely drivers of decline for the specific species and region
- Compare local trends to global patterns
- Clearly state confidence levels when data is sparse
- **Never invent statistics** — only interpret the provided data

This ensures outputs are grounded and transparent, not generic chatbot responses.
